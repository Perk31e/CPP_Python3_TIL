# 도전할 문제 **백준 16401**

## **백준 16401** (https://www.acmicpc.net/problem/16401) 도전

## 문제 - 백준 16401: 과자 나눠주기

M개의 과자가 있을 때, 과자를 동일한 길이로 잘라 N명의 조카에게 나눠주되, 그 길이를 최대화하는 문제

## 접근 방식

### 첫 번째 도전(baekjoon-1783.py)

이진 탐색(Binary Search)

**1. 최적화 문제의 특성**

- "최대 길이"를 찾는 최적화 문제인데, 특정 길이가 가능한지 여부를 쉽게 판단할 수 있음
- 이런 "결정 문제"로 변환 가능한 최적화 문제는 이진 탐색의 전형적인 적용 사례

**2. 단조성(Monotonicity) 존재**

- 과자 길이가 X라면, X보다 작은 모든 길이도 가능하고, X보다 큰 모든 길이는 불가능한 단조성을 가짐
- 이러한 특성은 이진 탐색의 전제 조건이 됨

**3. 탐색 범위가 큼**

- 과자 길이는 최대 10^9까지 가능하므로, 모든 길이를 하나씩 시도하는 것은 비효율적
- 이진 탐색을 통해 O(log(max_length)) 시간에 최적해 탐색 가능

**4. 판단 기준이 명확함**

- 특정 길이로 나눴을 때 조카 수보다 많은 조각이 나오면 길이를 늘리고, 적으면 줄이는 명확한 기준이 있음
- 이는 이진 탐색의 "더 큰 범위로 갈지, 더 작은 범위로 갈지"를 결정하는 핵심 요소

## 배운 점

1. **정수 나눗셈 주의**

   - `//` 연산자는 정수 몫을 계산
   - `(M + 1) // 2`로 2칸 아래 이동 횟수 계산

2. **경계 조건 처리**

   - 체스판의 크기에 따라 나이트의 이동 방식이 달라짐
   - 작은 크기의 체스판에서는 제한된 이동만 가능

3. **최솟값 계산**
   - `min()` 함수를 사용해 최대 이동 가능 칸 수 제한
