# 도전할 문제 **백준 2156**

## **백준 2156** (https://www.acmicpc.net/problem/2156) 도전

## 문제 - 백준 2156

포도주 시식에서 N개의 포도주 잔이 순서대로 놓여 있음
각 포도주 잔에는 특정 양의 포도주가 들어있음
다음 규칙을 지키면서 최대한 많은 양의 포도주를 마시는 문제

1. 포도주 잔을 선택하면 그 잔에 들어있는 포도주는 모두 마셔야 함
2. 연속으로 놓여 있는 3잔을 모두 마실 수는 없음

## 접근 방식

### 첫 번째 도전(baekjoon-2156-bruteforce.py)

풀이 방식: 구현 - 단순 반복문을 통한 시도
문제점: 모든 경우의 수를 체계적으로 고려하지 않아 최적해를 찾지 못함

```python
n = int(input())
cup = [int(input()) for _ in range(n)]

count = 0
total = 0
max_num = 0
# 최대안 cup 내 들어있는 많은 양을 고르되, 연속한 3컵을 고를 순 없다.

for i in range(n):
    for j in range(i, n):
        count += 1
        if count == 3:
            count = 0
            continue
        total += cup[j]
    max_num = max(total, max_num)
    total = 0

print(f"{max_num}")
```

### 두 번째 도전(baekjoon-2156-dp.py)

풀이 방식: 동적 계획법(DP) 활용
개선점: 각 위치에서 세 가지 선택(i번째 안 마심, i-1번째 안 마심, i-2번째 안 마심)을 고려하여 최적해 찾음

```python
n = int(input())
wine = [0]  # 인덱스를 1부터 시작하기 위해 0번 인덱스에 0 추가
for _ in range(n):
    wine.append(int(input()))

# dp[i]는 i번째 와인까지 고려했을 때 최대로 마실 수 있는 포도주의 양
dp = [0] * (n + 1)

# 초기값 설정
if n >= 1:
    dp[1] = wine[1]
if n >= 2:
    dp[2] = wine[1] + wine[2]

# 점화식을 이용한 DP
for i in range(3, n + 1):
    # 세 가지 경우를 고려
    # 1. i번째 와인을 마시지 않는 경우: dp[i-1]
    # 2. i번째 와인과 i-1번째 와인을 마시고, i-2번째 와인을 마시지 않는 경우: dp[i-3] + wine[i-1] + wine[i]
    # 3. i번째 와인을 마시고, i-1번째 와인을 마시지 않는 경우: dp[i-2] + wine[i]
    dp[i] = max(dp[i-1], dp[i-3] + wine[i-1] + wine[i] if i >= 3 else 0, dp[i-2] + wine[i])

print(dp[n])
```

## 배운 점

**동적 계획법(DP)의 중요성**

1. **서브프로블렘 정의**

   - dp[i]: i번째 와인까지 고려했을 때 최대로 마실 수 있는 포도주의 양
   - 명확한 상태 정의가 문제 해결의 핵심

2. **선택지 고려**

   - 각 단계에서 가능한 모든 선택지를 고려해야 함
   - 이 문제에서는 각 위치에서 세 가지 선택이 있음:
     1. 현재 와인을 마시지 않는 경우
     2. 현재 와인과 이전 와인을 마시는 경우(이전전 와인은 마시지 않음)
     3. 현재 와인을 마시고 이전 와인을 마시지 않는 경우

3. **초기값 설정의 중요성**

   - dp[1]과 dp[2]의 초기값을 올바르게 설정해야 함
   - 경계 조건(i < 3인 경우)을 적절히 처리해야 함

4. **점화식 해석**
   - dp[i] = max(dp[i-1], dp[i-3] + wine[i-1] + wine[i], dp[i-2] + wine[i])
   - 쉽게 표현하면:
     1. i번째 와인을 안 고름
     2. i-2번째 와인을 안 고름
     3. i-1번째 와인을 안 고름
