# 도전할 문제 **백준 18126 - 너구리 구구**

## **백준 18126 - 너구리 구구** (https://www.acmicpc.net/problem/18126)

## 문제

너구리 구구는 N개의 방이 있는 집에 살고 있습니다. 방들은 1번부터 N번까지 번호가 매겨져 있고, 양방향 통로로 연결되어 있습니다. 각 통로를 지날 때마다 특정 거리를 이동해야 합니다.

구구는 항상 1번 방에서 시작하여 다른 방들을 돌아다니다가 다시 1번 방으로 돌아옵니다. 이때 구구가 이동할 수 있는 최대 거리를 구해야 합니다.

## 접근 방식

### 풀이 방식 (baekjoon-18126.cpp)

풀이 방식: 깊이 우선 탐색(DFS)을 사용하여 1번 방에서 시작하여 갈 수 있는 모든 경로를 탐색하고, 최대 이동 거리를 구합니다.

```cpp
// 핵심 로직: DFS로 최대 거리 탐색
void dfs(int node, ll dist) {
    visited[node] = true;
    max_dist = max(max_dist, dist);

    for (auto& next : graph[node]) {
        int next_node = next.first;
        ll next_dist = next.second;

        if (!visited[next_node]) {
            dfs(next_node, dist + next_dist);
        }
    }
}

// 메인 함수에서 그래프 구성 후 DFS 호출
int main() {
    // 입력 및 그래프 구성 (생략)...

    // 1번 방에서 시작하여 DFS 탐색
    dfs(1, 0);

    cout << max_dist << endl;
    return 0;
}
```

## 코드 설명

1. **그래프 표현**: 각 방과 그 사이의 통로를 인접 리스트로 표현합니다. 각 연결은 (방 번호, 이동 거리) 쌍으로 저장됩니다.

2. **DFS 탐색**: 1번 방에서 시작하여 모든 가능한 경로를 탐색합니다. 이미 방문한 방은 재방문하지 않습니다.

3. **최대 거리 갱신**: 각 방문마다 현재까지의 누적 거리와 최대 거리를 비교하여 더 큰 값으로 갱신합니다.

## 깨달은 점

**효율적인 그래프 탐색**

1. **트리 구조의 특성 활용**

   - 방들이 트리 구조로 연결되어 있어 한 번 방문한 방은 다시 방문할 필요가 없습니다.
   - 방문 여부를 표시하는 배열로 중복 탐색을 방지합니다.

2. **거리 계산 효율화**

   - 각 경로마다 누적 거리를 계산하고, 최대값을 유지합니다.
   - 이동 거리가 큰 값일 수 있으므로 long long 자료형을 사용해 오버플로우를 방지합니다.

3. **양방향 그래프 구성**
   - 각 통로는 양방향이므로, 양쪽 방향 모두 그래프에 추가합니다.
   - 이를 통해 모든 가능한 경로를 탐색할 수 있습니다.

이 문제를 통해 트리에서 최대 거리를 구하는 방법과 DFS를 활용한 효율적인 그래프 탐색 기법을 배웠습니다.
