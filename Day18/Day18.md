# 도전할 문제 **백준 28069 - 김밥천국의 계단**

## **백준 28069 - 김밥천국의 계단** (https://www.acmicpc.net/problem/28069)

## 문제

김밥천국의 계단은 총 N개가 있으며, 0번 계단부터 시작하여 N번 계단에 도달해야 합니다. 계단을 오를 때는 두 가지 방법이 있습니다:

1. 한 계단 올라가기: 현재 위치에서 1칸 위로 이동
2. 점프하기: 현재 위치가 i일 때, i + ⌊i/K⌋ 위치로 이동 (⌊⌋는 내림 기호)

N번 계단에 도달할 수 있는지 여부를 판단해야 합니다.

## 접근 방식

### 풀이 방식 (baekjoon-28069.cpp)

풀이 방식: 다이나믹 프로그래밍을 사용하여 각 계단에 도달할 수 있는지 여부를 확인합니다.

```cpp
// 핵심 로직: DP를 활용한 최소 이동 횟수 계산
for (int i = 0; i <= N; i++) {
    if (dp[i] == -1) continue; // 아직 도달할 수 없는 계단

    // 한 칸 올라가기
    if (i + 1 <= N) {
        if (dp[i + 1] == -1 || dp[i + 1] > dp[i] + 1) {
            dp[i + 1] = dp[i] + 1;
        }
    }

    // 점프해서 올라가기 (i + [i/K])
    int jump = i + (i / K);
    if (jump <= N) {
        if (dp[jump] == -1 || dp[jump] > dp[i] + 1) {
            dp[jump] = dp[i] + 1;
        }
    }
}
```

## 코드 설명

1. **DP 배열 설정**: `dp[i]`는 i번째 계단에 도달하기 위한 최소 이동 횟수를 저장합니다. 초기값은 -1(도달할 수 없음)로 설정합니다.

2. **초기 조건**: 시작점인 0번 계단의 값을 0으로 초기화합니다.

3. **DP 업데이트**: 각 계단에서 가능한 두 가지 이동 방법을 시도하고, 더 적은 횟수로 도달할 수 있다면 값을 갱신합니다.

4. **결과 확인**: N번 계단의 dp 값이 -1이 아니라면 도달 가능한 것으로 판단합니다.

## 깨달은 점

**효율적인 DP 접근법**

1. **상태 정의의 중요성**

   - 각 계단에 도달하는 최소 이동 횟수를 기록함으로써 문제를 간결하게 해결할 수 있습니다.
   - 불가능한 경우를 -1로 명확히 구분하면 코드 가독성이 향상됩니다.

2. **두 가지 이동 방식의 처리**

   - 각 위치에서 두 가지 이동 방법을 모두 시도하여 최적의 경로를 찾습니다.
   - 점프 시 내림 연산(i/K)을 정확히 구현하는 것이 중요합니다.

3. **범위 체크의 중요성**
   - 계단 범위(0~N)를 벗어나지 않도록 항상 확인해야 합니다.
   - 점프 후 위치가 N을 초과하는 경우를 처리해야 합니다.

이 문제를 통해 동적 계획법을 활용한 효율적인 문제 해결과 여러 이동 방식이 있는 경우의 처리 방법을 배웠습니다.
